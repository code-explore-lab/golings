# 错误包装与判断

实现 `FindUser`：成功时返回名称；缺失时返回包含用户 ID、且保留 `ErrNotFound` 身份的错误。调用方应能添加上下文后继续判断错误原因。

在初始化后的本题目录运行 `go test ./...`，或运行 `gopath check 01-go-errors`。初始代码可以编译，但错误链检查会失败。只修改 `exercise.go`，保留测试。

验收：已存在的 ID 返回名称且无错误；空 map 或缺失 ID 返回可被 `errors.Is` 识别的错误，文本中包含查询 ID。
