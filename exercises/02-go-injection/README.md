# 小接口与依赖注入

实现基于 `Notifier` 接口的欢迎服务，通过构造函数注入发送依赖。练习窄接口和 fake 测试替身，无需邮件服务或网络。

在初始化后的本题目录运行 `go test ./...`，或运行 `gopath check 02-go-injection`。初始代码会忽略发送依赖，测试会指出缺失的调用和错误传播。

验收：每次欢迎调用恰好发送一次 `Welcome, Lin!` 形式的消息；依赖返回的错误可被调用方识别；缺少依赖时返回错误，避免 panic。
